# Onboarding SACI 2026/2

Repositório de **capacitação e nivelamento prático** para os novos membros do núcleo de estudos (**período 2026/2**).

Aqui você encontra as trilhas de onboarding. Cada uma reúne os materiais, os desafios e as instruções que devem ser seguidos ao longo do período.

## Como começar

1. Identifique a **trilha** em que você foi alocado(a) ou que escolheu.
2. Acesse a pasta correspondente em [`Trilhas/`](Trilhas/).
3. Siga as orientações daquela pasta para continuar.

Não avance pelos materiais de outra trilha: use apenas a sua.
